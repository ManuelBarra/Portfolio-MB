## ✨ CARACTERÍSTICAS ÚNICAS

### Diseño Visual
```
🎨 Tema Phoenician (fuego + oro + noche)
🎨 Tipografía jerárquica (Serif + Sans + Mono)
🎨 Layout asimétrico (63/37)
🎨 Colores contrastados (no gradientes)
🎨 Espaciado Fibonacci (no uniforme)
```

### Arquitectura
```
🏗️ Git como base de datos (JSON)
🏗️ CMS propietario (no Sanity)
🏗️ Admin panel custom (no genérico)
🏗️ SSG estático (performance)
🏗️ Vercel deploy (5 segundos)
```

### Desarrollo
```
👨‍💻 Setup en 30 minutos
👨‍💻 Admin en 2 horas
👨‍💻 En vivo en Vercel mismo día
👨‍💻 Editar sin código (JSON)
👨‍💻 Escalable pero simple
```
